# Capability sources

Leeds Harvester's 0.2 scrapers were planned by studying nine open-source scraping projects: what they collect, and how they get it. **No code was copied from any of them.** Their languages differ (Go, Java, Python and TypeScript), several licenses are incompatible with MIT or absent, and every Leeds Harvester capability is an independent implementation.

The rule for each idea was the same:

- **Built:** it collects public data through public pages or official public endpoints.
- **Declined:** it needs a login, private or mobile APIs, bot-challenge bypass, or targets individuals' personal data in bulk.

Studied on 2026-10-23 at each repository's default branch.

## Proposing a new source

A contribution is in scope when it collects public data through public pages or official public endpoints, follows `robots.txt` and the existing limits, and keeps source URLs on every record. See [CONTRIBUTING.md](../CONTRIBUTING.md#adding-a-scraper).
